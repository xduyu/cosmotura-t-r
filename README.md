# 🚀 COSMOTURA — Космическое туристическое агентство

Сайт космического туристического агентства, разработанный для муниципального этапа конкурса **«Цифровой ветер»** (номинация «Веб-разработка», категория 13–17 лет).

---

## 🌌 О проекте

Тема: **«Космическое туристическое агентство»** — сайт, предлагающий уникальные пакеты путешествий в космос: орбитальные станции, лунные маршруты, экспедиции на Марс и пояс астероидов.

---

## ✨ Особенности

- 🌟 Анимированное звёздное небо на Canvas (300 звёзд)
- 🌌 Живые туманности с плавной анимацией
- ⏱ Обратный отсчёт до следующего старта в реальном времени
- 🪐 Орбитальные кольца с вращением в hero-секции
- 💳 Интерактивные карточки туров с hover-эффектами
- 📺 Бесконечная бегущая строка с направлениями
- 📱 Адаптивная вёрстка

---

## 🛠 Технологии

- **Next.js 14** (App Router)
- **TypeScript**
- **CSS-in-JS** (встроенные стили, один файл)
- **Canvas API** для звёзд
- Шрифты: [Orbitron](https://fonts.google.com/specimen/Orbitron) + [Exo 2](https://fonts.google.com/specimen/Exo+2)

---

## 🚀 Запуск

```bash
npm install
npm run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)
